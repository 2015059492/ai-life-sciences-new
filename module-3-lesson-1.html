Module 3: Designing AI-Enhanced Lessons (Using TPACK & UDL Simply)

Lesson 1

Lesson Objectives

By the end of this lesson, teachers will be able to:

  1. Explain TPACK and UDL in simple terms.

  2. Understand how these frameworks guide AI integration in Life Sciences teaching.

  3. Identify opportunities to use AI meaningfully in a lesson.

1. What Is TPACK in Simple Words?

TPACK stands for:

  • Technological

  • Pedagogical

  • And

  • Content

  • Knowledge

This means combining three things:

  1. Content – what you teach (Life Sciences topics).

  2. Pedagogy – how you teach (discussion, inquiry, explanation, group work).

  3. Technology – the tools you use (AI tools, videos, images, simulations).

Good AI integration happens when all three work together.
For example:

  • Content: Genetics

  • Pedagogy: Comparing traits in a class

  • Technology: Using AI to generate a simple pedigree diagram

This is TPACK in action.

2. What Is UDL in Simple Words?

UDL (Universal Design for Learning) helps make learning accessible to all learners.

It focuses on giving:

  • Multiple ways to understand information (videos, text, diagrams)

  • Multiple ways to express learning (writing, drawing, voice notes)

  • Multiple ways to stay engaged (examples linked to real life)

AI supports UDL by helping you create different versions of the same content.

Examples:

  • AI simplifies complex terms for struggling readers.

  • AI generates a diagram for visual learners.

  • AI creates questions for learners who prefer practice.

3. How TPACK + UDL Work Together

Using both frameworks helps you plan lessons that:

  • are clear

  • include all learners

  • use AI in a purposeful way

  • support the CAPS curriculum

  • make teaching easier, not harder

For example:
Topic: Human digestive system

  • TPACK: Use AI to generate a labelled diagram + a short explanation

  • UDL: Provide three versions of the explanation (basic, intermediate, advanced)

This helps the whole class access the content.

4. Where AI Fits into Lesson Planning

AI can support different parts of your lesson:

  • Introduction: Give real-life examples

  • Teaching: Explain concepts simply

  • Practice: Generate questions or activities

  • Assessment: Create short quizzes

  • Differentiation: Adjust materials for different learning levels

AI should support the learning goals — not distract from them.

Reflection Question

Choose one Life Sciences topic you teach. How could AI help explain this topic more clearly using TPACK or UDL principles?
